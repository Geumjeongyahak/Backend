# Mistakes Ledger

작업하다 저지른 실수 한 건이 한 행이다. **리뷰가 잡은 것만이 아니라 스스로 알아챈 것도
적는다.** codex 지적은 [`findings-ledger.md`](findings-ledger.md)에 가고, 여기는 그
지적이 나오기 전에 막을 수 있었던 것 — 일하는 방식의 실수를 적는다.

이 원장을 두는 이유는 하나다. **같은 실수가 두 번째로 나왔을 때 그것이 두 번째임을
알기 위해서다.** 기억에 기대면 매번 처음 겪는 일이 된다.

## 적는 법

- `갈래` — 아래 「갈래」 표의 이름. 맞는 것이 없으면 새로 만들고 표에 더한다
- `어떻게 알았나` — 테스트 · 로그 · 리뷰 · 사람의 지적 중 무엇이 드러냈나
- `막는 법` — 다음에 같은 자리에서 무엇을 먼저 하면 되나. **「조심한다」는 막는 법이 아니다**

## 갈래가 두 번 나오면

같은 갈래가 **두 번째** 나오면 규칙으로 올린다.

| 실수가 드러나는 자리 | 올리는 곳 |
|---|---|
| diff를 보면 보인다 | [`rules/diff-signals.md`](v2/2026-08-08/rules/diff-signals.md)에 한 줄 |
| 계획에서 빠졌다 | [`rules/writing-a-plan.md`](v2/2026-08-08/rules/writing-a-plan.md) |
| 코드를 고치는 방식 | [`rules/changing-code.md`](v2/2026-08-08/rules/changing-code.md) |
| 테스트를 쓰는 방식 | [`rules/testing.md`](v2/2026-08-08/rules/testing.md) |
| 명령·도구를 쓰는 방식 | 아래 「갈래」 표의 `막는 법`을 굵게 바꾸고 워크플로의 해당 단계에 적는다 |

올린 뒤에는 `규칙` 칸에 올린 곳을 적는다.
